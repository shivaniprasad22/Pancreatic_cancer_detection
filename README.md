# 🔬 Pancreatic Cancer Detection – Machine Learning-Based Early Diagnosis

## 📌 Overview
Pancreatic cancer is one of the deadliest cancers, often diagnosed at late stages due to its asymptomatic early development and anatomical location. This project leverages machine learning (ML) techniques to detect pancreatic cancer early by analyzing clinical and biomarker data.

We evaluated various supervised learning models to identify the most effective approach for classification and diagnosis. The project emphasizes interpretability, performance, and real-world applicability.

---

## 🧬 Objectives
- Build ML models for early pancreatic cancer detection.
- Preprocess the dataset (handle missing values, encode labels, standardize features).
- Evaluate models based on performance metrics: accuracy, precision, recall, and F1-score.
- Visualize model effectiveness using confusion matrices.

---

## 🛠️ Workflow
1. **Data Preprocessing**
   - Missing value handling
   - Label encoding
   - Standardization

2. **Model Training**
   - Classifiers used:
     - Logistic Regression
     - Random Forest
     - Support Vector Machine (SVM)
     - XGBoost
     - K-Nearest Neighbors (KNN)

3. **Model Evaluation**
   - Accuracy
   - Precision
   - Recall
   - F1-score
   - Confusion matrix plots

---

## 📊 Results
- The best-performing classifier achieved:
  - **Accuracy:** 88%
  - Balanced performance across precision and recall.

These results demonstrate that ML models can play a vital role in supporting early pancreatic cancer diagnosis and improving patient prognosis.
